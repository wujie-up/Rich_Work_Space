# coding 项目内定位与浏览

场景：用户或 Agent 阅读本地 Java 与前端项目，沿定义理解代码。主要矛盾是纯文本与逐层进入目录打断阅读，而完整语言服务器超出最小可用范围。

只修改 coding：按需展开目录并保留兄弟节点；安全文本 token 高亮区分关键字、字符串、注释与数值，并按文件扩展名区分颜色；Java 通过轻量词法扫描识别类体中的类/方法声明，按名称返回候选 path/line/kind。候选不自动消歧，不处理依赖库、继承与重载语义。双击标识符或输入名称查找，点击候选定位；历史源码不触发当前项目定义搜索。

新增只读 code.definitions({name})，复用 Workspace 的路径、文件上限与目录忽略规则；每次查询扫描当前磁盘，不维护索引。扫描限制 10000 项、10 秒、100 个候选，支持停止并显式报告截断。

验收：领域测试覆盖声明/调用区分、重载、多行签名、嵌套类型、注释字符串、范围与取消；高亮恢复原文且不执行 HTML；真实包验证树展开/收起、源码样式、候选跳转、明暗主题与窄窗口，保留 Git/Maven 测试；构建并交付递增版本包，旧包保留。
