# 文本编辑器 0.1.56

在 Work Desk / RWork Space 的配置 → 插件 → 导入本地插件中选择 text-editor-0.1.56.plg，启用后点击图标打开。打开文件和另存为的目录选择框默认显示隐藏项，需要配套包含选择框修复的桌面；旧桌面中可按 ⌘⇧. 临时显示。

- 单窗口模式下，从工作台打开其他文件会在已有窗口切换到新文件，不重载页面；切换前保留未保存草稿。需要配套本次宿主窗口请求传递修复。
- 默认打开后正文为空，不自动打开历史文件或新建文档；左侧立即显示分组文件，左上角时钟图标查看最近访问的历史文件。拖动侧栏边界调整宽度，点击边界收起或展开，聚焦边界后用左右方向键调宽。点击“打开文件”或按 ⌘O / Ctrl+O 直接选择本地文本文件，只加入所选文件，不展开同级目录；直接使用文件原地址，保存写回原文件，不导入或复制到插件目录；取消选择保留当前文档，切换前保存未完成草稿。打开文件的原生选择框默认显示隐藏项目，也可按 ⌘⇧. 切换。新建文件时在弹窗填写名称和格式，普通保存默认写入工作台桌面 desktop-files；已打开的文件保存回原地址。另存为时填写新副本名称，再选择目标目录；不再提供打开文件夹入口。左栏保留打开和保存过的文件；分组、草稿和历史列表隐藏文件扩展名，前置 MD、TXT 等大写字母标识并以柔和颜色区分类型，无后缀和未知类型统一标识为 FILE，JSON 与 JSONC 统一标识为 JSON；悬停仅显示完整路径。分组纵向逐行显示，组名用独立颜色并加粗，文件缩进排列；点击分组行折叠或展开，键盘上下切换分组、左右折叠展开。支持新建分组；右键分组名或聚焦后按 Shift+F10，可重命名或删除该分组，也可点击顶部“分组操作”按钮；创建成功自动关闭弹窗，保存期间禁止重复提交；拖动文件调整顺序或拖到其他分组，Alt+上下方向键排序、Alt+左右方向键跨组。分组和顺序会保存，保存或重开不会打乱；删除分组会将文件移回“未分组”，不会移动磁盘文件。不覆盖已存在的另存目标。
- 左侧分组和历史中的文件支持右键“复制文件”，聚焦文件条目后也可按 Ctrl/Cmd+C；复制原文件引用，在 Agent 会话中粘贴为待发送文件，不复制磁盘文件、不自动发送，使用磁盘上已保存的内容，正文选区仍按原生方式复制。左侧文件右键支持重命名、移除记录和删除文件；重命名不覆盖同名文件。减号移除历史记录，保留磁盘文件；若对应当前文档，先保留未保存草稿再关闭正文，草稿保存失败则保留正文和历史记录。移除其他历史记录不影响当前文档。删除需确认并删除实际文件，同时保留未保存内容为草稿。键盘可用 Shift+F10 打开菜单、方向键选择、Esc 关闭，点击外部或执行操作后自动收起。
- 支持 UTF-8 TXT、XML、JSON/JSONC、Markdown、YAML 及其他纯文本；单文件最大 16 MiB（按实际 UTF-8 字节数计算），保留已有 BOM 和 CRLF/LF。保存与草稿采用分片传输，切换未修改的文件只清理旧草稿标识，避免大文本超过桌面单次请求上限。暂不支持其他编码、超大文件及二进制。
- 编辑区按后缀自动语法高亮，支持 SQL、JSON/JSONC、Markdown、YAML、XML/HTML、JavaScript/TypeScript、CSS、Python、Java 和 Shell。关键字、字符串、数字等使用不同颜色，注释与强调使用斜体或粗体，适配明暗主题；纯文本与未知格式保留原样。解析在独立线程完成，不影响原生撤销、搜索和输入；超过 512 Ki 字符的文件保留纯文本编辑，不限制原有 16 MiB 打开和保存能力。
- 编辑区使用独立的蓝灰底色，左侧显示原始文本行号；自动折行不增加编号，行号随滚动、字号和窗口宽度变化对齐，仅渲染可见行号。阅读和演示模式隐藏行号，分栏时仅在编辑侧显示，明暗主题分别适配。
- JSON/XML/YAML 点击“格式化”，确认后保存；JSON 与 JSONC 统一使用 JSON 类型，均兼容注释和末尾逗号，新建格式不再单列 JSONC，保存已有文件保留原后缀；格式化失败保留原文。JSON/YAML 格式化保持大整数原始精度，YAML 浮点数也保留原始数字文本。
- 文件操作和右侧编辑、阅读、分栏、格式化、演示、字号工具在顶部同一行，始终显示。Markdown 支持编辑、阅读、左右分栏；分栏按原文段落及表格行位置双向同步滚动，字号、窗口和图形高度变化后重新对齐；PlantUML 文件支持直接预览。Markdown 代码块语言使用 mermaid、plantuml 或 puml。
- 点击搜索图标或按 ⌘F / Ctrl+F 搜索当前文档，默认忽略大小写并按文字匹配；显示当前结果与总数，Enter / Shift+Enter 或上下箭头按钮循环定位，Esc 关闭。编辑和分栏定位原文选区，阅读和演示定位并高亮渲染后的文本；搜索不改写文件。
- Markdown 文档右上角显示章节大纲，按标题层级排列，支持点击定位预览或编辑位置；进入文档时显示，闲置 3 秒后用 1.2 秒淡出，移入右上角区域或键盘聚焦时保持显示，移出后淡出。手机触摸不会锁定显示，触摸后闲置 3 秒自动淡出，再次轻触右上角区域可展开。编辑后自动更新，无章节标题和非 Markdown 文档不显示。遵循系统减少动态效果设置。
- 阅读或分栏时点击绘图可打开独立查看器，支持 25%–400% 缩放、重置与滚动查看；缩放控件在右侧居中，进入查看器或移入该区域时显示，闲置 3 秒隐藏，键盘聚焦期间保持显示。Esc 或“关闭”返回正文；聚焦绘图后也可按 Enter 或空格打开。
- 点击工具栏“演示”全屏展示当前全文（含未保存内容），Markdown 和绘图沿用预览，其他格式保留原文；滚动查看，Esc 或“退出演示”返回原显示模式。宿主需向插件开放全屏权限。
- 所有绘图引擎随包，不需要 Java、Python、Graphviz 安装或联网。PlantUML 使用官方 @plantuml/core 1.2026.9 JavaScript/TeaVM 版本；不保证 Java 版所有功能。外部 include、标准库 include、网络图像和链接跳转不提供，内置主题可用。Mermaid 使用 strict 模式。
- 单个图代码限 20,000 字符；PlantUML SVG 限 4096 像素。复杂图形可能耗时，优先使用小图。
- 未保存文本自动写入插件独立草稿，左侧“草稿”固定分组位于最上方，使用独立颜色，支持折叠展开，不可改名、删除或拖入磁盘文件。新建空文档也保留为草稿；点击条目恢复，保存成功后移出草稿分组。新建或打开其他文件前也会保存草稿。删除草稿不可撤销。多个窗口分别维护当前文档。
- 保存检测外部修改，发生冲突时保留草稿，需重新打开文件或另存为。当前文件未保存内容不会因格式化失败被清空。
- 跟随桌面当前主题；⌘S / Ctrl+S 保存，Shift+⌘S 另存为，Tab 插入两个空格，支持编辑器原生撤销。

## 开发与打包

在此目录运行 `npm ci --ignore-scripts`，仓库根运行 `node plugin-dev/text-editor/build/build.mjs`。
产物为 `plugin-dev/dist/text-editor-0.1.56.plg`，gzip tar，包含浏览器资源、独立后端和第三方许可证，不包含 node_modules 或开发工具。
插件协议与扩展规范见仓库 `docs/plugin-development.md`。安装不修改其他插件数据；本插件草稿存于宿主 `plugin-data/text-editor/`。
