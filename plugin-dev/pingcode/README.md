# PingCode 任务 0.4.0

默认通过配套 Chrome 扩展复用你当前浏览器中的 PingCode 登录，按人员、角色、月份查询任务及任务价值分总值，无需 Client ID、Secret 或令牌。原独立窗口和 OpenAPI 方式保留。

本版需要同时升级插件和配套浏览器扩展到 0.4.0。请先停用旧扩展，再加载新版目录并重新连接；旧扩展会提示升级，不会回退到全部月份读取。

网页登录查询直接向 PingCode 传递所选月份的起止时间，只读取该范围的分页及必要详情。默认当前月、完成时间；切换月份或创建/完成时间后重新查询。分页最多 3 个并行请求、详情最多 4 个并行请求；失败或取消不展示部分总分，不使用跨次查询缓存。

打开插件、恢复显示及扩展重连时会自动检查浏览器连接和 PingCode 登录，无需手动刷新。相同账号检查不会清空当前任务；账号变化或登录失效会使旧结果失效。未连接时显示连接说明，不自动打开配对页；查询期间不插入自动检查。

## 安装并连接现有 Chrome

1. 在插件中心导入 plugin-dev/dist/pingcode-0.4.0.plg。
2. 在当前 Chrome 打开 chrome://extensions，停用旧版配套扩展，启用开发者模式，点击“加载已解压的扩展程序”，选择 plugin-dev/dist/pingcode-browser-extension-0.4.0 文件夹。也可解压 plugin-dev/dist/pingcode-browser-extension-0.4.0.zip 后加载解压目录。
3. 返回插件点击“登录 PingCode”。在本机连接页点击连接图标，然后在扩展自己的确认页核对本机地址并点击允许图标。
4. 返回插件等待自动检查登录状态（也可手动重试）。扩展会复用相同站点的已有标签页；没有时在当前浏览器打开新标签页。如需登录，在该页完成后再次检查。
5. 搜索并选择人员，角色可选负责人、开发负责人或测试负责人，切换角色或项目会自动重新查询；默认当前月、完成时间，可切换创建时间，清空月份查看全部时间。

普通连接页可关闭。查询期间关闭 PingCode 标签页会使当前读取失败；下次查询会在现有浏览器中重新打开。完全退出 Chrome 后无法查询，再打开浏览器后扩展会尝试恢复配对连接。
工作台停止插件只断开本机连接，不关闭用户浏览器、标签页或系统登录。点击“断开浏览器连接”会移除此配对，不退出 PingCode 账号。扩展可访问 Chrome 配置文件中已有的 PingCode 登录，不复制或导出 Cookie。

扩展最低 Chrome 116，权限仅 storage、scripting、alarms 以及 PingCode HTTPS 子域和本机回环地址。仅支持 PingCode 公有云站点；私有部署可使用独立窗口或 OpenAPI。
配对密钥只保存在插件独立数据目录 browser-bridge.json（0600）和 Chrome 扩展存储中，不随包交付。本机桥仅监听 127.0.0.1，端口与密钥首次生成后保留；后台查询始终有超时和取消处理。

## 可选独立登录窗口

在插件配置中将“网页登录方式”切为“独立登录窗口”并保存。此方式仍依赖登录窗口，关闭后须重新打开。资料按站点保存在 plugin-data/pingcode/browser/，不复制系统浏览器或飞书登录；退出登录仅清除此插件窗口资料。当前独立窗口仅验证 macOS 与已安装的 Google Chrome。

## 可选 OpenAPI 方式

切换为 OpenAPI 模式后，在插件配置中填写：

1. 选择已有访问令牌，或企业应用凭据（Client ID / Client Secret）。凭据由 PingCode 企业后台的凭据管理提供。
2. 公有云 OpenAPI 地址使用 `https://open.pingcode.com`；企业站点使用 `https://qxsh20230413015201829.pingcode.com`。
3. 默认项目为“全平台开发任务”，项目 ID `64fc8d0c8198e2525bef8537`；留空查询全部可访问项目。
4. 价值分字段键默认为 `renwujiazhifen`，对应“任务价值分”，与故事点不同。
5. 保存配置后返回查询页，输入姓名并搜索，选择负责人后自动查询任务。项目刷新按钮加载可访问项目，并重新查询已选人员的任务。

企业令牌按官方说明具有管理员级权限，应使用专门应用并配置所需的数据范围。用户令牌按对应用户的权限查询。
凭据仅由后台保存在 `plugin-data/pingcode/connection.json`，文件权限 0600；界面只读取是否已配置。
留空保留原凭据，勾选删除显式清除；更换 API 地址时清除旧凭据。企业应用令牌在需要时重新获取；已有令牌过期后需要重新配置。
网页登录不能替代 OpenAPI 授权。插件不复制系统浏览器或飞书 Cookie，不修改远端工作项。

月份按本机时区计算，包含月初、不包含下月月初。按完成时间筛选时，没有完成时间的任务不计入当月；清空月份可查看全部时间。
OpenAPI 模式仍读取接口分页后在本地按月筛选，尚未验证该模式的服务端月份条件；本版减少跨月份请求的优化适用于网页登录方式。

任务按全部分页读取并按 ID 去重，父子工作项按各自的分值分别累计；已归档、已删除项不计入。
状态筛选同步更新列表和总分。未填写及非法值不计分且单独计数，零分有效。小数按十进制精确累计。
分页中断、权限失败、限流、超时及取消不会把部分结果呈现为完整总分。查询结果是查询时快照，不是实时订阅。

## 开发与交付

从仓库根目录执行：

```sh
npm run build
node --test --test-concurrency=1 plugin-dev/pingcode/test/*.test.js
npm run pack:plugin -- plugin-dev/pingcode/dist/package
```

构建会生成只含运行时文件的 `dist/package/`，使用统一打包命令重新校验并生成标准 gzip tar `.plg`。
完整性清单为 SHA-256，不是发布者签名。包不包含测试夹具、开发依赖或实际凭据。

网页登录的人员候选来自当前账号可见项目成员。按月查询使用原生只读搜索接口：时间范围和项目在服务端筛选，普通负责人也在服务端筛选；开发负责人、测试负责人在月份范围内按自定义字段精确匹配。包含所有工作项类型，所以条数可能多于单独的“需求”视图。
页面接口随站点升级可能变化，结构不符合已核实结果时明确报错，不返回猜测总分。

本次真实网页登录验证：吴杰在全平台开发任务下有 31 个未归档工作项，8 项填写分值，总值 25；DKY-695 为 5。
这是查询时快照，属于网页登录验证，不是 OpenAPI 授权验证。原 0.1.0 和 0.2.x 包保留，不覆盖；上述 31 项/25 分是全部时间口径，不代表当前月统计。
0.4.0 在 2026-10-30 实测当前月两种时间口径、三种角色，六组请求均未调用全历史列表。吴杰的开发负责人角色按创建时间为 24 项/68 分，按完成时间为 19 项/60 分；结果为当时快照。真实 MV3 扩展测试验证了按月搜索分页、复用标签页和断线重连。
测试还包含隔离界面夹具、模拟协议和真实 Chrome 资料保留/清除验证。OpenAPI 实连接仍需要有效凭据。
官方协议：[PingCode REST API V2](https://open.pingcode.com/)。
