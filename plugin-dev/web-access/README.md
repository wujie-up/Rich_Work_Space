# 远程访问 0.1.23

macOS（Apple Silicon）工作台插件及 macOS/iOS 原生助手。仅提供工作台 Web 和已启用插件视图的固定服务通道，禁止指定任意目标、IP、端口、CONNECT、SOCKS 或 VPN。

## 使用

1. 使用包含 `desk.service-transport.v1` 的新版工作台；在被访问的 Mac 桌面设置中开启网页服务并创建账号。旧版宿主不支持该插件。
2. 导入 `plugin-dev/dist/web-access-0.1.23.plg`，在原生工作台的“远程访问”页面开启访问并创建邀请。
3. 连接端 Mac 安装同一个插件，点击工具栏显示器图标“打开内置电脑助手，连接其他工作台”，无需另装 App，也无需开启连接端的网页服务。助手保留独立窗口，关闭最后一个窗口即退出；插件禁用或工作台退出也会关闭助手。iOS 继续使用手机助手。
4. 在助手中粘贴邀请，填写设备名称，请求配对。在被访问的原生工作台核对双方显示的设备指纹后确认。邀请两分钟过期，一次使用；请通过可信渠道传递。
5. 在助手点击连接，已授权绑定的设备直接进入工作台首页，无需输入网页账号密码（须配套本次更新的宿主）。需要撤销时在原生工作台删除设备；停止访问会断开全部远程连接并撤销其网页会话。

助手按工作台身份隔离 WebKit HTTP 资源缓存，每次连接先清除 Cookie、存储等业务会话数据，再加载并获取当前连接的临时设备会话。手动断开时销毁页面和网络连接；iOS 短暂失焦不再断开，进入后台后申请最多 20 秒运行时间。期限内连接正常时保留当前页面；超过期限或系统提前收回运行时间时释放连接，返回前台后自动重新连接并获取新的设备会话，不重放业务请求。Mac 主机须保持运行且不休眠。

## 网络和权限边界

使用官方开源 [iroh 1.2.0](https://github.com/n0-computer/iroh-ffi/tree/v1.2.0) 和 [iroh Node](https://github.com/n0-computer/iroh-nodejs)。连接优先尝试 QUIC P2P 直连，直连约 8 秒未成功时回退获准使用的美国西部 n0 公共加密中继。国内免注册且明确允许第三方接入的兼容节点尚未确认，暂时跳过国内层，不使用未获准的节点。主机保持中继可发现以接收兜底连接，公共发现及中继协调流量可能出境，不能据此宣称全部流量在境内。无需自有公网服务器，也不使用 Cloudflare。旧配对保留身份与直连地址，忽略旧中继提示；回退仅使用显式批准的节点。身份验证、服务授权失败不触发换节点重试。

- 设备身份验证、短时随机邀请、挑战证明、本机二次确认；私钥与设备审批分别存放在插件隔离数据目录及助手 Keychain。
- Web 端接收上下文绑定运行实例和设备，独立会话绑定，设备间及局域网之间不互用会话。只给助手公开证书；私钥留在 Web 领域。助手对本次身份认证通道得到的证书固定校验，校验有效期和回环主机名，无全局证书信任变更。
- 配置、配对、撤销仅原生桌面可调用，网页和其他插件服务调用均拒绝。
- 每设备最多 32 条流、全局 128 条；最多 32 个连接/授权、8 个待确认设备，邀请每分钟 5 次；所有设备双向合计超过 10 MiB/s 会断开触发超限的连接，不自动重试。
- 账号共享工作空间和全部已启用插件权限；不提供账号间数据隔离。插件是可信本地代码，独立进程不是恶意代码权限沙箱。

## 构建与交付

仓库根目录：

```sh
npm install --prefix plugin-dev/web-access --ignore-scripts
npm run build -- --desk-only
npm run build --prefix plugin-dev/web-access
npm run pack:plugin -- plugin-dev/dist/.staging-web-access
node --test plugin-dev/web-access/test/*.test.js web/test/*.test.js desk/test/plugin-native.test.js
```

构建需在 Apple Silicon Mac 上安装 Swift 6+ Command Line Tools；首次解析官方 IrohLib 依赖需联网。打包清单包含编译后的内置助手，并显式排除 Apple 源码/缓存、开发依赖和用户数据。`.plg` 含 macOS arm64 官方原生 iroh 引擎；当前不声明 Intel Mac 支持。助手只从插件内固定路径启动，不接受程序路径或启动参数；启动入口仅原生桌面可调用。包内助手保持临时签名，未做开发者签名和公证。

助手源码及构建说明见 [assistants/README.md](assistants/README.md)。macOS 最低 15；iOS 目标 27.2。iOS 真机安装需要完整 Xcode、iOS 27.2 SDK 和 Apple 开发签名；不能仅靠插件安装到手机。

当前验收覆盖本机真实 QUIC、TLS、会话隔离和撤销；公网首次握手经 n0 中继后升级直连。实际 macOS WebKit 固定证书登录、错误证书拒绝及独立来源插件 iframe 已通过；已补齐 Web 证书 serverAuth 用途，旧证书下次开启 Web 时更新。iPhone 家庭 Wi-Fi 已确认登录及打开插件；0.1.10 蜂窝加密中继已由用户确认显示页面并登录，但页面加载慢、切换应用断开仍需改进。尚未完成长时间稳定性、设备撤销真机复验和上架审核。

0.1.4 修复单条网页连接结束导致整台设备断线的问题。真实 macOS WebKit 已验证登录页空闲 8 秒后仍可登录并打开插件；iPhone 家庭 Wi-Fi 已由用户确认持续连接、登录并打开插件；蜂窝连接仍超时，尚未通过。

0.1.5 增加助手连接阶段、网络类型及中继就绪诊断，超时提示包含最后阶段；不记录邀请、密钥或网页内容，不改变连接策略和访问边界。

0.1.6 增加前 60 秒限量传输统计与流日志时间，辅助定位蜂窝网络资源下载停滞；蜂窝已确认加密连接、授权及主页面 HTTP 200，完整页面仍白屏，尚未通过。

0.1.7 启用一次性传输库 INFO 诊断，记录手机本地中继主机名；蜂窝出现 QUIC 接收统计连续 30 秒停止增长，原因仍在排查，不能视为验收通过。

0.1.8 对照实验：助手有邀请中继地址时仅选择该中继，保留 P2P 打洞；用于区分跨中继路径问题。蜂窝完整访问仍待实测，不作为稳定版本结论。

0.1.9 撤回未解决超时的单中继实验；电脑端增加最近 128 条阶段及前 60 秒传输统计，保存在插件数据目录 `connection-diagnostics.json`，不记录协议帧或 Web 内容。诊断写入失败不影响授权与转发；蜂窝仍未通过。

0.1.10 根据同一 iPhone 蜂窝网络的隔离对照，将电脑及手机的公共中继固定为美西；旧邀请仅更新中继提示，保留设备身份、配对和直连地址。256 KiB 合成数据经新加坡在 75 秒内仅收到约 9 KiB，美西 6.3 秒完整校验通过；随后用户已确认蜂窝加密中继显示界面并登录；尚未确认蜂窝下插件操作的完整稳定性。固定区域仅针对本次已验证网络，不代表其他运营商的最优路径；直连与全部访问边界不变。

0.1.11 调整手机生命周期：短暂失焦保持连接，后台申请最多 20 秒运行时间，连接释放后返回前台自动重新连接；手动断开仍清除本次网页登录。配套宿主为静态 HTML/JS/CSS/SVG 协商 gzip，保留 no-store、认证与固定服务边界，登录/RPC 不压缩；该宿主改动不包含在插件包中。此版本的切换应用行为与压缩收益仍需 iPhone 实测。

0.1.12 内置同一构建的工作台外壳，HTTPS 主文档协商版本；版本不匹配或注入失败回退远程加载。插件完整性摘要参与静态 URL，已列入清单的 HTML/JS/CSS/图片/字体/Wasm 可私有缓存，JSON、API、错误和未版本化文件保持 no-store；绝对路径资源仍走原服务。每台工作台、每项固定服务使用稳定独占回环端口，占用时回落随机端口。首页三个只读请求并行，预取不跨会话持久化。需要配套新版宿主；插件正文不重写。实机性能待更新后确认。

0.1.14 优化远程访问管理界面：复用公共控件修复深色图标对比度，设备与连接分栏并适配窄窗口；待确认区域仅在收到请求时显示。技术说明收纳到帮助提示，工作台访问权限仍直接显示；设备 ID 单行省略并可查看全文，配对指纹完整展示。仅调整管理界面，不改变连接、认证和配对协议。使用隔离界面夹具验证明暗主题、窄窗口、邀请及配对/撤销参数；不代表蜂窝网络故障已完成实机复验。

0.1.22 暂停自动中继：电脑和助手均禁用 RelayMode，旧邀请不再带入中继路由；直连超时明确提示未启用中继。解除启动时等待 home relay 的条件，避免纯直连模式启动一直等待；仅限工作台 Web 服务的授权、免登录与撤销边界保持原契约。国内节点未验证前不添加自动兜底。
