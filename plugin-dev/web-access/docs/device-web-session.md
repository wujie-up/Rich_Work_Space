# 已绑定设备直接进入工作台

场景：已在电脑确认的手机，每次建立身份已验证的远程连接后直接进入工作台首页。
主要矛盾：设备已获授权，但 Web 再次要求密码，重复认证增加操作和加载等待。

仅由 Web 服务持有的传输接收器签发随机临时会话。会话摘要存于内存，绑定当前 grant，最长八小时；不创建网页账号，不保存密码，不接受 HTTP 头声明设备身份。普通浏览器继续使用原账号登录。

实施顺序：先用隔离临时目录验证失败用例，再增加 transport 设备会话和 workspace 引导、事件校验，更新助手提示，构建相关资源。Agent 后台及合包继续等待用户说明。

验收：授权连接首次 GET /api/session 返回会话和安全 Cookie；可进入插件首页；跨 grant 和 LAN 拒绝复用；Origin、CSRF 和固定服务白名单继续有效；撤销时拒绝在途请求、结束事件流并清除会话；退出后须重连。设备授权独立于网页账号删除。
