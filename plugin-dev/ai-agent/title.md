# AI Agent 会话（0.5.2）

提供独立安装的 Codex、Claude Code 与自定义 CLI 会话、权限选择、恢复与分叉、终端布局与回放、Git 分支操作。全部能力归属本插件，desk 仅提供运行机制。

向工作流提供通用只读 Agent 任务、菜单计划、代码及任务读取/审批/取消能力。通用任务通过 `agent.task.start.v1` 发布，由工作台发现和协调；未填目录时使用插件隔离运行空间。计划使用只读原生线程；代码任务要求确认文件列表，比较工作目录实际内容以拦截范围外修改，并输出文件前后内容及摘要。取消关闭任务引擎；重启将未完成任务标记中断，不自动重放。菜单任务不暴露任何外部能力工具，普通对话也不暴露任务接口，避免递归调用。
