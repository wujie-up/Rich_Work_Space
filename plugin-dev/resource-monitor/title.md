# 资源监控 0.1.0

在工作台右上方查看插件后台及其可归属子进程的 CPU、RSS 内存、网络下载和上传趋势。面板可拖动，标题栏的收起按钮将它变为小横条，采样继续；展开按钮恢复图表。标题栏可用方向键移动，也可在普通窗口中打开并平铺。

默认每 2 秒采样，保留最近 120 个点；插件配置可选择 2、5、10 秒及首次显示时是否收起。已有位置与收起状态优先保留。关闭后停止采样，侧栏再次打开可恢复；停用/卸载沿用工作台通用流程，默认保留设置。

CPU 按全部逻辑核心归一化到 0–100%，内存为 RSS，可能含共享页。合计仅覆盖当前运行插件后台与可归属子进程，不代表整台电脑占用。Electron 共享界面/网络进程不计入，短命进程可能遗漏。网络速率来自系统按进程计数的采样差分，连接退出或计数重置时重新建立基线；含本机回环流量，不等于物理网卡带宽。无法取得的数据以横线和原因显示，初次采样需要等待下一次基线。

当前实现与验证目标为 macOS arm64；其他平台显示采集不可用。依赖系统 ps/nettop，不提权、不安装抓包证书，不记录连接正文或持久化进程历史。需要支持 desk.overlays.v1、desk.runtime-directory.v1、desk.settings.v1 的新版宿主，先更新宿主，再从插件中心导入 `.plg`。

插件无第三方运行依赖；随仓库 MIT 许可证交付。
