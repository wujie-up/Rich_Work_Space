# 桌面界面约束

- 设置界面保持简洁：删除与标签、字段或现有控件重复的标题、说明和操作；不常驻展示版本提示、操作教程等与当前设置无关的内容。每个设置项保留一个清晰入口。
- 设置弹窗优先合并导航与关闭操作，减少独立标题栏和底部提示栏；操作按钮优先采用简单线条图标，必要的导航和字段名称保留文字。
- 桌面及插件工作台的操作按钮统一使用简洁的 SVG 线条图标，包括清空输入、换行、分叉、展开菜单、改名、折叠和关闭等操作。
- 复用所属模块现有图标按钮实现；使用 `currentColor`、无填充和一致的尺寸、线宽，不用文字、Unicode 符号、Emoji 或实心图案替代操作图标。
- 操作图标默认不带图框、描边容器或常驻底色，保留键盘聚焦提示。
- 图标按钮必须保留明确的 `aria-label` 和悬停提示；菜单同时支持鼠标悬停和键盘聚焦展开。
- 同插件存在其他窗口（含最小化窗口）时，关闭只移除当前外壳，保留其他窗口和共享后台任务；关闭最后一个窗口必须先二次确认，再经宿主已有生命周期流程归档任务并结束插件进程，取消时保留窗口和任务。

- 正式工作台只允许一个运行实例，重复启动应激活已有窗口；只有显式测试模式且指定独立数据目录才允许隔离运行。macOS 安装及更新统一使用应用程序目录中的 `DeckPg.app`，替换同名版本，不创建版本号应用副本；保留配置、插件及历史数据，不清理用户数据目录。

- macOS 构建和打包测试产物必须放在 `desk/dist/releases.noindex/` 等不被 Spotlight 索引的目录，不得将测试副本放入 Applications，也不得启动正式副本进行隔离测试。测试继续使用显式测试参数及临时数据目录。
- 每次打包、安装、更新和隔离测试结束后，必须执行 `npm run check:mac-installation`：仅保留 `/Applications/DeckPg.app` 的正式启动登记，同时检查 Launch Services 和 Spotlight，不能只凭注册记录判断应用列表已去重。发现重复入口须清理并重新验证后再报告完成；不得重置整个系统应用列表或删除用户配置、插件、历史数据。系统应用列表仍有重复时必须实际检查该列表，不得直接声称已解决。
- macOS 更新统一执行 `npm run install:mac`，只替换正式应用包，安装前检查运行状态，安装后自动去重并验证；检查失败须回滚应用包。不得手动保留可被索引的旧 `.app` 副本。
