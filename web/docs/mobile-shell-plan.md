# 手机 Web 工作台实施清单

场景：手机通过高延迟加密链路操作已有工作台。主要矛盾是桌面侧栏与标签占用窄屏、触控操作困难；复用已有视图和窗口状态，避免切换页面重新加载插件。

已确认：登录、首页、全屏插件、窗口切换和账号入口适配手机；插件正文保持现状，桌面布局不变。服务边界、认证和 RPC 不增加权限。

实现：只在 web 浏览器适配层按视口重排现有 DOM；窗口选择及账号菜单复用共享 popup.js，外观复用 controls.css。首页复用插件列表和工作台文件，底部三个入口至少 44px。退出手机布局或会话失效时撤销适配和监听。
